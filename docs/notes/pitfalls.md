# 踩坑复盘：术语页这一轮反复踩到的 12 类坑（2026-10-28）

每次都是「看起来小、改了两三遍才对」。按「现象 → 根因 → 以后怎么做」记，做新功能前扫一眼。

## 一、协作与版本

**1. 两个会话同时改一个工作区。**
现象：编译不过、提交里混进别人的改动、文件被莫名改写（`ranking/mod.rs` 被外部写三次）。
根因：同一份 checkout 没有「谁在写」的约束。
规矩：**一个工作区只有一个写入者**。收工时 `git status` 全看一遍；提交只 `git add` 明确路径，
不要 `git add -A <目录>`（这次就把别人改的 `docs/plan/todo.md` 扫进了我的提交）；
发现外部改动先备份成 `.patch`/分支，再决定合不合。

**2. WIP 分支会过时。**
现象：`fix/core-ranking` 停在半成品，后续完整实现又进了另一支。
规矩：WIP 分支只当历史留档，不合入；合入顺序写在进度板上（谁依赖谁）。

## 二、命令与编码（Windows）

**3. 中文弯引号 + 带空格路径。**
现象：PowerShell 报「意外标记 status」。
根因：聊天里复制出来的是 `“ ”`；PowerShell 里带空格路径要 `&` 调用。
规矩：命令一律英文直引号；路径带空格就用 `& "…"`。

**4. `python -c` 传中文被编码破坏。**
现象：`SyntaxError: invalid character '（'`，或字符串被吃掉引号。
规矩：**任何带中文的脚本都写成 `.py` 文件再跑**（`.toolchain/*.py`），不要塞进 `-c`。

**5. `.cmd`/`.ps1` 里的中文。**
现象：`rem 中文` 那行被当成命令；`chcp 65001` 也救不了被 ANSI 解析的正文。
规矩：批处理脚本**只写 ASCII**；非要中文就存带 BOM 的 UTF-8（PowerShell 5.1）。

## 三、沙箱与构建

**6. 沙箱禁止命名管道。**
现象：Server 在 Agent 里启动即 `exit 101`，但用户桌面上的 Server 活得好好的。
规矩：**需要管道/窗口/桌面交互的进程，交给用户双击**（`update.cmd`）。Agent 只负责编译、验证日志。

**7. `link.exe` 报 `LNK1104`（打不开 Temp 里的 .tmp）。**
现象：同样的代码前一次能编，这次链接失败。
根因：沙箱对 `%TEMP%` 的写限制。
规矩：构建前把 `TMP`/`TEMP` 指到工作区（`.toolchain/tmp`）。

**8. 二进制被占用。**
现象：`cargo build` 拒绝访问、`Compress-Archive` 报文件被另一进程使用。
根因：用户开着设置程序 / Server 正在跑。
规矩：打包前先确认没在跑；构建必要时换 `--target-dir`。

**9. git 身份没配。**
现象：`fatal: unable to auto-detect email address`。
规矩：新机器先 `git config --local user.name/email`（与既有提交作者一致）。

## 四、UI 布局与交互（bamboo-slip）

**10. 立即模式 UI 每帧整页重排。**
现象：术语页 735 条时卡顿；debug 版更明显。
规矩：长列表要有行数上限（现 60 条）+ 单行截断，别用折行 `paragraph` 铺上千节点；
卡顿先把列表行数降下来再谈优化。

**11. 页头把内层滚动区撑爆（这次真正的根因）。**
现象：滚动条看不见、拖不动、内容被窗口裁掉。
根因：页头在 1240px 窗口里占 820px，内层 `ScrollArea` 的视口被撑到 **6526px**，
比窗口还高——既没有滑块，也没有可视滚动区。
规矩：**要自己滚的区域必须给确定高度**（内容区高度 − 页头），不要指望 `flex_grow`
在「内容比容器高」时自动生效；页头控件超过 3 行就该收进页签。
排查手法：打印 `interaction.rect(key)` 与 `scroll_extent(key)`，**看数字不要猜**。

**12. 滚动条拖拽三连坑。**
a. 命中取「最后注册的元素」→ 滑块注册在视口之前，永远被视口盖住；
b. 用绝对位置当偏移 → 一按就跳回顶部；
c. 外层没溢出的 `ScrollArea` 仍注册指针交互 → 盖住里层滑块。
规矩：滑块交互要在视口**之后**注册；拖动用「本帧位移 ÷ 滑块可走距离 × 可滚范围」**累加**；
滚动区不溢出（≤1px）就不注册指针交互。

## 五、数据权威与热加载

**13. 同一份译名有两处来源，改了一处不生效。**
现象：术语表里「围挡 → hoarding」，候选窗还是 `barricade`。
根因：候选窗注解读的是 `user-glossary-<语言>.tsv`（个人释义表优先），那份只由云端兜底写。
规矩：**一处权威 + 派生文件自动重算**。术语是权威；保存术语时重算个人释义表；
派生文件头写「由 X 生成，别直接改」。

**14. 热加载漏了用户数据文件。**
现象：改完术语必须重启 Server。
根因：热加载只盯 `config.toml` 与 `dicts/`、`codes/` 快照。
规矩：**任何用户可改的输入文件都要进热加载快照**（现在含 `user-terms.tsv` 与五份
`user-glossary-<语言>.tsv`，每秒看 mtime + 长度）。

**15. 协议没变才能只换 Server。**
规矩：`PROTOCOL_VERSION` 没动、DLL 没改 → 只换 exe 即可（不用 regsvr32）；
改了协议就必须 Server + DLL 成对换并重启应用。

## 六、数据清洗

**16. 正则双重转义。**
现象：过滤 `v卫生间…` 这类列表残留的正则失效，脏数据进了词库。
根因：脚本里写成了 `r"\\u4e00"`（匹配字面反斜杠）。
规矩：正则里的 Unicode 区间写 `r"[\u4e00-\u9fff]"`；改完拿真实样本跑一遍断言。

**17. 并列词与括注。**
现象：「监测 / 检测」「竣工（图纸中）」自动注音失败、混进候选。
规矩：并列词拆成独立词条；括注当备注去掉；含拉丁字母的词无法注拼音 → 标「不进候选」。

**18. 生成物别当源文件。**
现象：手改 `user-glossary-en.tsv`，下次重算就没了。
规矩：派生文件写头注释；设置页只让改源（`reviewed.xlsx`、`user-terms.tsv`）。

## 七、验证与交付

**19. 组件测试过了不等于能用。**
现象：bamboo-slip 的拖拽单测过了，真窗口里仍然拖不动（是布局问题）。
规矩：**用户报的现象，先写一条端到端复现**（真实 `Runner` 走事件链，或真实 Server 日志），
再改代码；修完那条测试必须转绿。

**20. 「日志里没有预期行」就是证据。**
现象：以为热更新生效，实际跑的还是安装版。
规矩：验证功能是否生效，抓日志关键行（词库路径、`术语表已加载`、`释义表已切换`），
不看日志不下结论。

**21. 交付形态。**
规矩：出包用文件夹 `dist\青简-<YYYYMMDD>-<序号>\`（两个 exe + `update.cmd` + `说明.txt`），
不打压缩包；说明里写「这版改了什么、怎么验、怎么回退」。

## 一句话版

> 先量数字再改代码；一处权威、派生自动重算；用户能改的文件都要热加载；
> 要自己滚的区域给确定高度；修用户报的 bug 先写端到端复现；收工前 `git status` 与日志都要看。
