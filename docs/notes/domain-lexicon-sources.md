# 领域词库数据源调研（2026-10-23）

为个人术语表与随包领域词库找「能合法再分发、能商用」的中文词表。六个目标领域：工程施工 / 项目管理 /
建筑设计 / 机电 / 商业品牌 / 二次元。许可一栏标「已核」的是亲自打开过 LICENSE 或条款原文。

## 结论

1. **五个工作领域的现成词表全部不可用。** 术语在线（termonline.cn）明文禁止复制 / 传播 / 转载 / 汇编，
   仅限非商业个人使用；国家标准全文公开系统页脚「版权所有 侵权必究」，推荐性国标受著作权保护；
   国标术语章逐条抄就是复制。二级来源（各类「术语大全」网站、GitHub 上的建筑词表）要么无许可、要么是转载。
2. **二次元与商业品牌有干净来源，但量不大。** Wikidata 是 CC0（动画类中文标签约 2,230 条，品牌未测）；
   中文维基百科 CC BY-SA 4.0（动画术语 43 页、电子游戏术语 161 页、中国品牌 103 页）。
3. **最稳的一条路是自建 300–800 条核心术语表**：单个术语与短语通常不受版权保护，受保护的是「汇编」与
   「释义文字」，所以自己整理（或 LLM 起草后人工审）的清单风险为零，而批量导出 80 万条反而危险。
4. 扩大覆盖靠**语料挖词**：政府公开文件（著作权法第五条，不适用著作权）与中文维基 dump，喂现有的
   `dict-convert mine` 管线。

## 语料路线（配 `dict-convert mine`）

- **中文维基 dump**（CC BY-SA 4.0，已核）：百科体，挖工程 / 建筑 / 机电 / 项目管理术语最有效。
- **住建部与地方住建局公文、征求意见稿**（无版权，已核）：最贴工程施工与项目管理。
- **GitHub 中文文档**（MIT/Apache 仓库可）、FreeCAD / IfcOpenShell / Blender 手册（CC BY-SA / LGPL，需逐一核）：
  建筑、机电的补充。
- LCCC（项目记录为 MIT，本次 HuggingFace 不可达）：口语，只适合二次元与网络新词。
- **不可用**：新闻语料（版权）、BCC（仅研究）、百度百科 / 知乎 / CSDN / 弹幕。

管线：领域底表 + 上述语料 → `mine` 出 `oov-filtered.tsv` → `gloss-gen pinyin` 补读音 → `dict-convert lexicon --extra-words`。

## 合规要点

- 数据文件独立许可（mere aggregation）：CC BY-SA 数据与 GPL 代码可以并存，只要 `assets/<源>/LICENSE` + 署名页列出。
- CC BY-SA 4.0 与 GPLv3 单向兼容（CC 官方声明，已核）。
- **单个术语/短语一般不受版权**；受保护的是「汇编」与「释义文字」。所以人工/LLM 整理的 300–800 条核心表远比
  批量导出第三方词库安全。
- 政府公文本身不适用著作权，但**附件是不是公文的一部分存在解释空间**：只作语料、不整段复制，发布前由维护者确认。
